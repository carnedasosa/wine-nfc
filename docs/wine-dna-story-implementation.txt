SOVRANATURALE — WINE DNA STORIES
Implementation notes, 2026-09-30

Flow
Wine DNA → Crea la tua storia → preview → composition/palette/name/details → share or save PNG.
Canvas export: 1080 × 1920. Preview and downloaded PNG use the same canvas.
No per-user image-generation call, no additional AI cost for changing a story.
The story uses the already-loaded tastings and is available while the text analysis is pending.
Six palettes follow recorded emotions; three compositions are stable per user/event, with manual override.
Preferences are kept on this device by user and event. Only graphical preferences are stored, never the name, email, tastings, or generated PNG.
Typography and illustrations are self-hosted and included in the static service-worker cache.
No database migration, backend API change, or production deployment is part of this change.

Assets
assets/story/bottle.png and assets/story/glass.png were created with the built-in image_gen tool using the approved collage as reference, then copied into the workspace. Genuine transparent backgrounds.
assets/story/sovranaturale-source.png is the user's original screenshot, unchanged. The renderer crops surrounding space and uses the existing lettering. Its original resolution remains a limit; an original vector logo can replace it later.
Fonts: Anton and Kalam, from google/fonts, with bundled OFL licenses.
https://github.com/google/fonts/tree/main/ofl/anton
https://github.com/google/fonts/tree/main/ofl/kalam
